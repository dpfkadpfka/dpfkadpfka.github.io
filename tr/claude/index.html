PART 4 · WHAT IS MCP

MCP란?

MCP = Model Context Protocol · 모델 컨텍스트 프로토콜

AI와 앱을 잇는 공용 규격"AI용 USB-C 단자"처럼 하나로 통일
한 번 만들면 어느 AI에서나앱 회사가 만들면 여러 AI가 같이 써요
2024.11 앤트로픽이 공개지금은 업계 표준
근거: MCP 공식 문서 (modelcontextprotocol.io) · 앤트로픽 발표 2024.11

PART 4 · WHY MCP

MCP가 뜨는 이유

연결 규격이 하나로 통일

AI 4개 × 앱 100개 = 400번 → 앱마다 한 번만 만들면 끝

업계 표준으로 자리잡음

2024.11 앤트로픽 공개 → 2025.12 리눅스 재단 이관 · OpenAI · 구글 · MS 참여

말만 하던 AI가 일을 하게 됨

메일 보내기 · 일정 만들기 같은 실행은 외부 연결이 필요해요

서비스가 빠르게 늘어남

활성 서버 약 1만 개 · SDK 월 9,700만 다운로드 (2025.12 기준)
